Уровень 3.10 задачника JavaScript

№1Дан массив.
Сделайте так, чтобы в нем каждый элемент повторился два раза.

№2 Дан массив и число.
Оставьте в массиве только те числа, которые являются делителями заданного числа.

№3 Даны два числа.
Получите массив цифр, которые есть и в одном, и во втором числе.

№4 Дано число.
Получите массив позицией всех цифр 3 в этом числе,
за исключением первой и последней.

№5 Дан массив со числами.
Оставьте в нем числа, состоящие из разных цифр, а остальные удалите.

№6 Дан массив:
[
[1, 2, 3],
[4, 5, 6],
[7, 8, 9],
]
Слейте элементы этого массива в один одномерный массив:
[1, 2, 3, 4, 5, 6, 7, 8, 9]
