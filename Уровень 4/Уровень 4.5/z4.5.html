Уровень 4.5 задачника JavaScript

№1 Дана переменная со строкой. Проверьте, что в эта строка
представляет собой число, то есть состоит только из цифр.

№2 Дана переменная со строкой. Проверьте,
что в эта строка представляет собой дробь.

№3 Сделайте функцию, которая параметром будет принимать массив
с числами и возвращать второе по величине число.

№4 Сделайте функцию, которая параметрами будет принимать два числа
и возвращать массив, заполненный целыми числами от минимального параметра до максимального.

№5 Сделайте функцию, которая заполнит массив случайными латинскими буквами.

№6 Сделайте функцию, которая будет возвращать сумму N первых чисел Фибоначчи.
