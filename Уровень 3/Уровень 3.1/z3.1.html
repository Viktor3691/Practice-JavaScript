Уровень 3.1 задачника JavaScript

№1 Дано некоторое число.
Проверьте, что цифры этого числа расположены по возрастанию.

№2 Дан массив:[1, '', 2, 3, '', 5]
Удалите из массива все пустые строки.

№3 Дан массив:
[
[2, 1, 4, 3, 5],
[3, 5, 2, 4, 1],
[4, 3, 1, 5, 2],
]
Отсортируйте элементы в каждом подмассиве.

№4 Даны два массива:
let arr1 = [1, 2, 3];
let arr2 = [1, 2, 3, 4, 5];
Удалите из большего массива лишние элементы с конца так,
чтобы длины массивов стали одинаковыми.
